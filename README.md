# QA Portfolio

## 소개
일본 IT QA 취업을 목표로 만든 포트폴리오입니다.
비전공 출신으로, 2026년 4월부터 QA 기초 학습과 실습을 진행하고 있습니다.

## 학습 기간
2026년 4월 ~ (진행 중)

## 포트폴리오 구성

### 1. 수동 테스트 (TodoMVC)
- 기능 테스트 케이스 다수 (한국어)
- 버그 리포트 (한국어 + 일본어)
- 발견한 버그: 긴 문장 입력 시 텍스트 깨짐, 입력값 삭제 시 항목 자동 삭제 등

### 2. API 테스트
- JSONPlaceholder API GET 요청 테스트

### 3. 자동화 테스트 (Playwright)
- TodoMVC 대상 E2E 자동화 테스트 8~9개
- 기본 기능(추가/삭제/체크/필터), 경계값 테스트(빈 값 입력) 포함

### 4. 실무형 테스트 계획서 (Plane 프로젝트)
- 정식 테스트 계획서 작성
- 이슈별 상세 테스트 케이스 (우선순위, 마감일, 상태 변경, 필터링)
- 심각도 분류 적용

## 학습한 QA 개념
- 테스트 유형 (기능/비기능)
- 테스트 레벨 (단위/통합/시스템/인수)
- 동치 분할 및 경계값 분석
- 버그 라이프사이클
- 심각도(Severity) vs 우선순위(Priority)
- 테스트 케이스 vs 테스트 시나리오
- 회귀 테스트 vs 스모크 테스트
