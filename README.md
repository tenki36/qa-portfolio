# QA Portfolio

## 소개
일본 IT QA 취업을 목표로 만든 포트폴리오입니다.
- 기간: 2026년 4월~6월
- 목표: QA 기초 + 자동화 테스트 역량 확보

## 포트폴리오 구성

### 1. 수동 테스트 (4월)
- 테스트 케이스 9개 (한국어)
- 버그 리포트 3개 (한국어)
- 테스트 케이스 2개 (일본어)
- 버그 리포트 2개 (일본어)

### 2. API 테스트 (5월)
- JSONPlaceholder API 테스트 3개

### 3. 자동화 테스트 (6월)
- Playwright를 사용한 E2E 자동화 테스트 5개
  - 할 일 추가 테스트
  - 할 일 삭제 테스트
  - 할 일 목록 개수 확인
  - 완료된 항목 스타일 확인
  - 입력칸 초기화 확인

## 기술 스택
- Playwright (자동화)
- Node.js
- JavaScript

## 테스트 대상
- TodoMVC (React)
- JSONPlaceholder API
