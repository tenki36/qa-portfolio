# イシュー2: 優先度変更テスト

テストケース1
- タイトル: 優先度を「高」に変更
- 手順: イシュー選択 → 優先度「High」をクリック → 保存
- 期待結果: 優先度が「High」と表示される
- 深刻度: Major

テストケース2
- タイトル: 優先度変更後もリストに反映
- 手順: 優先度変更 → リストに再度アクセス
- 期待結果: 変更した優先度が維持される
- 深刻度: Minor

テストケース3
- タイトル: 優先度による並び替え機能
- 手順: 「並び替え: 優先度」をクリック
- 期待結果: 高い順 → 中間 → 低い順に並ぶ
- 深刻度: Minor

# イシュー4: ステータス変更テスト

テストケース1
- タイトル: Backlog → Todo へステータス変更
- 手順: イシュー選択 → ステータス「Todo」をクリック
- 期待結果: ステータスが「Todo」に変更される
- 深刻度: Critical

テストケース2
- タイトル: In Progress → Done へステータス変更
- 手順: ステータスを「In Progress」→「Done」に変更
- 期待結果: ステータスが「Done」と表示される
- 深刻度: Critical

テストケース3
- タイトル: ステータス変更履歴の記録
- 手順: ステータスを複数回変更後、履歴を確認
- 期待結果: 全てのステータス変更履歴が表示される
- 深刻度: Minor

- タイトル: 優先度でフィルタリング
- 手順: フィルター →「優先度: High」を選択
- 期待結果: High のイシューのみ表示される
- 深刻度: Major

テストケース2
- タイトル: ステータスでフィルタリング
- 手順: フィルター →「ステータス: Todo」を選択
- 期待結果: Todo のイシューのみ表示される
