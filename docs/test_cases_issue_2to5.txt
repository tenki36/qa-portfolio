# 이슈 2: 우선순위 변경 테스트

테스트 케이스 1
- 제목: 우선순위 높음으로 변경
- 단계: 이슈 선택 → 우선순위 "High" 클릭 → 저장
- 예상 결과: 우선순위가 "High"로 표시
- 심각도: Major

테스트 케이스 2
- 제목: 우선순위 변경 후 목록에 반영
- 단계: 우선순위 변경 → 목록 재진입
- 예상 결과: 변경된 우선순위 유지
- 심각도: Minor

테스트 케이스 3
- 제목: 우선순위 정렬 기능
- 단계: "정렬: 우선순위" 클릭
- 예상 결과: 높음 → 중간 → 낮음 순으로 정렬
- 심각도: Minor

# 이슈 3: 마감일 설정 테스트

테스트 케이스 1
- 제목: 마감일 설정 후 표시

- 심각도: Major

테스트 케이스 2
- 제목: 지난 날짜 설정 불가
- 단계: 지난 날짜 (2026-06-01) 설정 시도
- 예상 결과: 에러 메시지 표시
- 심각도: Major

테스트 케이스 3
- 제목: 마감일 알림 기능
- 단계: 마감일 1일 전 로그인
- 예상 결과: 알림 표시
- 심각도: Minor

# 이슈 4: 상태 변경 테스트

테스트 케이스 1
- 제목: Backlog → Todo 상태 변경
- 단계: 이슈 선택 → 상태 "Todo" 클릭
- 예상 결과: 상태가 "Todo"로 변경
- 심각도: Critical

테스트 케이스 2
- 제목: In Progress → Done 상태 변경
- 단계: 상태를 "In Progress"로 → "Done"으로 변경
- 예상 결과: 상태가 "Done"으로 표시
- 심각도: Critical

테스트 케이스 3
- 제목: 상태 변경 이력 기록
- 단계: 상태 여러 번 변경 후 이력 확인
- 예상 결과: 모든 상태 변경 기록 표시
- 심각도: Minor

# 이슈 5: 필터링 테스트

테스트 케이스 1
- 제목: 우선순위로 필터링
- 단계: 필터 → "우선순위: High" 선택
- 예상 결과: High 이슈만 표시
- 심각도: Major

테스트 케이스 2
- 제목: 상태로 필터링
- 단계: 필터 → "상태: Todo" 선택
- 예상 결과: Todo 이슈만 표시
- 심각도: Major

테스트 케이스 3
- 제목: 여러 필터 동시 적용
- 단계: "우선순위: High" + "상태: In Progress" 선택
- 예상 결과: 두 조건 모두 만족하는 이슈만 표시
- 심각도: Minor
