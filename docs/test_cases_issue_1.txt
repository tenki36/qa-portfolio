테스트 케이스 1
- 제목: 이슈 기본 정보 입력 후 생성
- 단계:
  1. 프로젝트 진입
  2. "Create Issue" 버튼 클릭
  3. 제목 입력: "기능 버그 테스트"
  4. 설명 입력: "로그인 안 됨"
  5. "Create" 버튼 클릭
- 예상 결과: 이슈가 생성되고 목록에 표시
- 심각도: Critical

테스트 케이스 2
- 제목: 필수 필드 없이 생성 시도
- 단계:
  1. "Create Issue" 클릭
  2. 제목 비우고 "Create" 클릭
- 예상 결과: 에러 메시지 표시 ("제목 필수")
- 심각도: Major

테스트 케이스 3
- 제목: 마감일 설정 후 생성
- 단계:
  1. "Create Issue" 클릭
  2. 제목 입력
  3. 마감일 설정 (내일)
  4. "Create" 클릭
- 예상 결과: 마감일이 설정된 이슈 생성
- 심각도: Minor
