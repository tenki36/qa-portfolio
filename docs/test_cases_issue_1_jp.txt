---

```
# イシュー1: イシュー作成テスト

テストケース1
- タイトル: 基本情報を入力してイシューを作成
- 手順:
  1. プロジェクトに入る
  2. 「Create Issue」ボタンをクリック
  3. タイトルを入力: 「機能バグテスト」
  4. 説明を入力: 「ログインできない」
  5. 「Create」ボタンをクリック
- 期待結果: イシューが作成され、リストに表示される
- 深刻度: Critical

テストケース2
- タイトル: 必須項目を入力せずに作成を試みる
- 手順:
  1. 「Create Issue」をクリック
  2. タイトルを空欄のまま「Create」をクリック
- 期待結果: エラーメッセージが表示される（「タイトル必須」）
- 深刻度: Major

テストケース3
- タイトル: 期限を設定してイシューを作成
- 手順:
  1. 「Create Issue」をクリック
  2. タイトルを入力
  3. 期限を設定（明日の日付）
  4. 「Create」をクリック
- 期待結果: 期限が設定されたイシューが作成される
- 深刻度: Minor
```
